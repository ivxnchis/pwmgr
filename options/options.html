Import from Chrome or Edge

  1. Chrome: open chrome://password-manager/settings → Export passwords → Download file.
  2. Edge: open edge://wallet/passwords (or edge://settings/passwords) → ⋯ / Settings → Export passwords.
  3. Pick the downloaded .csv below, then delete that CSV — it contains your passwords in plain text.

Export

Downloads a Chrome-compatible CSV (unencrypted). Handy as a backup or to move back to Chrome/Edge.

Fields where autofill is off

Add one by right-clicking a field on any page → PwMgr → Turn autofill off / on for this field. The extension also clears values Chrome's own password manager puts in those fields.
